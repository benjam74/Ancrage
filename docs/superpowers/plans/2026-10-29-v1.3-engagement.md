# v1.3 — Accroche et envie d'avancer : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rendre la régularité plus facile et plus gratifiante : retour vivant en séance, fin de manche en deux écrans, série visible et réparable, bonus de retour, objectif réglable, comparaison à sa propre moyenne, distance au palier, rendez-vous d'agenda, réglages de motivation.

**Architecture:** Tout ce qui se calcule vient de l'historique (fonctions pures de `src/core`), comme la série et l'XP aujourd'hui. Les préférences de l'appareil vivent dans `localStorage` (`src/app/prefs.ts`), hors sauvegarde et hors synchronisation. Son et vibration passent par `src/ui/feedback.ts`.

**Tech Stack:** inchangée (Web Audio et Vibration API du navigateur, aucune dépendance).

**Spec:** `docs/specs/2026-10-29-v1.3-engagement-design.md` ; recherche : `docs/research/2026-10-29-engagement-research.md`.

## Global Constraints

- Barème inchangé : 10 XP par carte due, 5 par nouvelle, 0 en avance, 20 par manche ; nouveau : `XP.comeback = 20`.
- Bonus de retour : première manche d'un jour d'étude dont le jour d'objectif précédent date d'au moins 3 jours d'étude.
- Réparation : un jour manqué sans gel ne casse pas la série si le jour d'étude suivant compte ≥ 2 manches ; deux jours manqués d'affilée ne se réparent pas ; les gels passent avant.
- La série tient avec une manche ; l'objectif du jour (1, 2 ou 3 manches, défaut 1) est séparé.
- Anneau : cible = max(1, min(objectif × 10, réponses du jour + cartes encore disponibles aujourd'hui)).
- Compteur « d'affilée » visible à partir de 3.
- Jalons de série : 7, 30, 100, 365.
- Préférences de l'appareil (clé `ancrage.prefs`) : `sound`, `haptics`, `motion`, `showStreak` (booléens, vrai par défaut), `dailyRounds` (1–3, défaut 1), `plan` (`{ time: 'HH:MM'; cue: string } | null`). Valeur invalide → valeur par défaut.
- Aucun message ne dit « série perdue » ni ne culpabilise.
- Sons, vibrations et animations désactivables ; `prefers-reduced-motion` coupe les animations.

2. **Bonus de retour compté une seule fois par jour** même avec plusieurs manches, et jamais pour la toute première manche de l'historique. → test Task 1.

4. **Peu de cartes disponibles** (3 cartes et objectif 3 manches) : l'anneau peut se remplir. → test Task 3.
5. **Série masquée** : aucune pastille, aucun bandeau, aucun écran Série, mais le calcul ne change pas. → vérif e2e Task 6.
