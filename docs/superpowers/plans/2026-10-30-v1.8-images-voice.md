# v1.8 — Images masquées et voix : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nouveau type de note « Image masquée » et voix (lecture, dictée) en séance.

**Architecture:**
- L'image (data URL compressée) et ses zones (coordonnées relatives 0–1) vivent dans les champs de la note ; elles sont donc synchronisées et sauvegardées comme le reste.
- Les exercices existants (choix, saisie, révélation) reçoivent une figure facultative.
- La voix passe par les API du navigateur (`speechSynthesis`, `SpeechRecognition`) dans `src/ui/voice.ts`.
- La langue est un champ facultatif des thèmes et domaines.

**Spec:** `docs/specs/2026-10-30-v1.8-images-voice-design.md`.

## Global Constraints
- Zone : `{ id, x, y, w, h, label }`. Coordonnées dans [0, 1], `w` et `h` ≥ 0,02, rectangle entièrement dans l'image.
- Image : `data:image/…`, côté ≤ 1 280 px, 700 Ko au plus après compression.
- Langues : `fr-FR` (défaut), `en-GB`, `es-ES`, `de-DE`, `it-IT`.
- `BACKUP_VERSION = 4`.
